# Компилятор учебного языка Jack

## Quick-start

Класс `Compiler` - основной для использования.

Компилятор имеет один позиционный аргумент - путь до `.jack` файла или папки.

Если передать папку в качестве аргумента - компилятор рекурсивно пройдет по всем подпапкам данной папки и обнаружит все
файлы с расширением `.jack`.

Для запуска:

```bash
uv run python .\main.py "Путь до .jack файлов" --no-run
```

Скомпилированные `.vm` файлы будут находиться в директории `./build`

## Аргументы

```bash
positional arguments:
  path                  Путь к .jack файлу или папке

options:
  -h, --help            show this help message and exit
  -o, --out-path OUT_PATH
                        Папка для .vm (default ./build)
  -g, --grammar-file GRAMMAR_FILE
                        Путь до файла грамматики jack
  -s, --states-file STATES_FILE
                        Путь до SLR-таблицы
  --build-grammar       Пересобрать SLR-таблицу
  --ignore-build-exist  Игнорировать предупреждение о перезаписи и удалении файлов
  --show-resolved-funcs
                        Вывод информации об обнаруженных функциях
```

## ВНИМАНИЕ

- Менять файл грамматики без надобности и понимания происходящего не рекомендуется.
- При добавлении нетерминала или терминала требуется изменение кода компилятора (`CodeGenerator` и тд.)
- Стандартная build-директория будет очищаться полностью. Другие - для безопасности иных данных просто перезапишут новые
  vm файлы.
  (Для отключения предупреждения см. `ignore-build-exist`)
